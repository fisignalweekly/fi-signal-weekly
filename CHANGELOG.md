# Changelog

Production releases of the FI Signal Weekly site. Entries are dated in Eastern Time and listed newest first. Version numbers follow semantic versioning: the patch number increases for a data publish, the minor number for a feature, and the major number for a breaking change.

## v1.0.0 (2026-11-19, ET)

First formally versioned production release of a site that has been live and stable. This baseline covers the current live site, including the mobile-first redesign, the signup fallback, the directory, and the board. Later data publishes bump the patch number; features bump the minor number.

The read-only data server is versioned separately as mcp-v1.0.0 on the mcp-server-src branch.
